# モードの音のフォルダ

列車モードの走行音と、旅のお供の音（川・雨・祭り…）を入れるフォルダです。

## 列車の走行音

`train.mp3`（`train.m4a` `train.wav` なども可）を置くと、列車モードで旅をしている間に鳴ります。

- 発車すると、再生の速さ（playbackRate）と音の高さが少しずつ上がっていきます（加速）
- 巡航の速さは **普通 1.0**・**特急 1.4**
- 休憩・一時停止で駅や信号場に止まるとき、だんだん下がって消えます
- 継ぎ目はクロスフェードせず、サンプル単位でそのままつなぎます。
  頭と終わりがつながるように切り出した「ループ用」の録音がいちばん自然です
  （エンコーダーが足す先頭・末尾の短い無音は自動で外します）

設定 → 列車の「走行音」で切れます。

## そのほかの音（river.mp3・rain.mp3・festival.mp3 …）

`train` 以外のファイルは、**サウンド → ミキサー → 環境音** に並びます（`public/ambient/` と同じ扱い）。
題名や絵文字を決めたいときは `sounds.json` に書きます（書き方は `public/ambient/README.md` と同じ）。

```json
{
  "sounds": [
    { "file": "river.mp3", "title": "川のせせらぎ", "emoji": "🏞️" },
    { "file": "festival.mp3", "title": "夏祭り", "emoji": "🏮", "gain": 0.7 }
  ]
}
```
