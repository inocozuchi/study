# BGM のフォルダ

ここに入れた曲が、アプリの **サウンド → BGM** に並びます（ミキサーで音量も変えられます）。

## 追加のしかた

1. このフォルダ（`public/bgm/`）に音声ファイルをアップロードする
   - GitHub なら、このフォルダを開いて **Add file → Upload files**
2. `main` に入ると自動で公開され、数分でアプリに出てきます

`tracks.json` を書かなくても、ファイル名が曲名になって一覧に出ます。

## 曲名などを決めたいとき（任意）

`tracks.json` に書きます。書いた順番で並び、書いていないファイルは後ろに並びます。

```json
{
  "tracks": [
    { "file": "morning-field.mp3", "title": "朝の草原", "subtitle": "My Lo-Fi" },
    { "file": "campfire.m4a", "title": "焚き火", "gain": 0.8 }
  ]
}
```

| 項目 | 内容 |
|---|---|
| `file` | ファイル名（必須） |
| `title` / `subtitle` | 表示する曲名・補足 |
| `gain` | 0〜2。曲ごとの大きさの差をそろえる（既定 1） |
| `crossfade` | 秒。ループ用に作られていない曲の継ぎ目を重ねる長さ（既定 0） |
| `loopStart` / `loopEnd` | 秒。ループする範囲を決めたいとき |
| `trimSilence` | `false` にすると先頭・末尾の無音を自動で外さない |

## ループについて

- Web Audio API のバッファループで、曲が終わった瞬間に途切れず頭へ戻ります（フェードも無音も入りません）。
- MP3 / AAC がエンコード時に足す先頭・末尾の短い無音は自動で外します。
- 継ぎ目で波形が飛ぶ曲は、数ミリ秒だけ重ねて「プチッ」を消します（聞いてわかる長さではありません）。
- 1 ファイルは GitHub の制限（Web からのアップロードは 25MB まで）に収めてください。
