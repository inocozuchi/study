# 環境音のフォルダ

ここに入れた音声ファイルが、アプリの **サウンド → ミキサー → 環境音** に並びます。
雨・川・焚き火・カフェ・電車など、勉強しながら流したい音を入れてください。

## 追加のしかた

1. このフォルダ（`public/ambient/`）に音声ファイルをアップロードする
   - GitHub なら、このフォルダを開いて **Add file → Upload files**
2. `main` に入ると自動で公開され、数分でアプリに出てきます

`sounds.json` を書かなくても、ファイル名が題名になって一覧に出ます。
絵文字はファイル名から推測します（`rain` や `雨` → 🌧️、`川` → 🏞️、`fire` や `焚き火` → 🔥 など）。

## 題名・絵文字・音量を決めたいとき（任意）

`sounds.json` に書きます。書いた順番で並び、書いていないファイルは後ろに並びます。

```json
{
  "sounds": [
    { "file": "rain.mp3", "title": "しとしと雨", "emoji": "🌧️" },
    { "file": "campfire.m4a", "title": "焚き火", "emoji": "🔥", "gain": 0.8 },
    { "file": "river.wav", "title": "川のせせらぎ", "crossfade": 3 }
  ]
}
```

| 項目 | 内容 |
|---|---|
| `file` | ファイル名（必須） |
| `title` | 表示する名前（省略するとファイル名） |
| `emoji` | アイコンの絵文字（省略するとファイル名から推測） |
| `gain` | 0〜2。音ごとの大きさの差をそろえる（既定 1） |
| `crossfade` | 秒。ループの継ぎ目で終わりを頭に重ねる長さ（既定 1.5） |
| `loopStart` / `loopEnd` | 秒。ループする範囲を決めたいとき |

## ループについて

- Web Audio API のバッファループで、途切れずに無限ループします。
- 録音をそのまま入れても「プチッ」と鳴らないよう、継ぎ目で終わりの 1.5 秒を頭に重ねてつなぎます（音量は下がりません）。
- 30 秒〜2 分くらいの長さがおすすめです（長すぎると iPhone のメモリを多く使います）。
- 形式は MP3 / M4A(AAC) / WAV / FLAC / OGG など。iPhone では MP3・M4A・WAV が確実です。
